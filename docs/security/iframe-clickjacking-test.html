Prueba de bloqueo de clickjacking - PAEC

Este archivo se abre localmente con file:// (o servido desde otro origen). Intenta embeber la app PAEC dentro de un <iframe>. Si los headers de seguridad estan correctamente configurados en el nginx del frontend, el iframe debe fallar y aparecer un error en la consola del navegador.

Pasos:
  1. Levantar el frontend: docker compose up -d --build frontend.
  2. Abrir este archivo con doble click (se abre con protocolo file://).
  3. Abrir DevTools (F12) → pestana Console.
  4. Verificar que el iframe queda en blanco / con error y que aparece un mensaje del tipo "Refused to display ... in a frame because it set 'X-Frame-Options' to 'DENY'" o "Refused to frame ... because an ancestor violates the Content Security Policy directive: 'frame-ancestors none'".
  5. Tomar captura de pantalla de la consola + del panel Network mostrando los response headers de localhost:5173.

Iframe hacia http://localhost:5173

Si el iframe muestra la aplicacion, los headers NO estan bien configurados y hay que revisar frontend/nginx.conf.
